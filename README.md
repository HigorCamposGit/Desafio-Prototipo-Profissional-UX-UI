# 🍽️ Sabor Brasileiro Express — Protótipo Profissional UX/UI

Projeto de conclusão da **Formação UX/UI Designer** da [DIO (Digital Innovation One)](https://www.dio.me/), aplicando todas as etapas de concepção de um produto digital: desde a análise de briefing e pesquisa com usuários até a construção do Design System, prototipação interativa de alta fidelidade e orçamento comercial.

---

## 🎯 Sobre o Projeto

O **Sabor Brasileiro Express** é uma proposta de aplicativo mobile de pedidos próprios desenvolvido para um restaurante de comida brasileira e pratos executivos. O objetivo central é eliminar gargalos no atendimento manual via WhatsApp nos horários de pico e reduzir a dependência de marketplaces de terceiros.

4. **[Orçamento e Proposta Comercial](./proposta-comercial.md)**
